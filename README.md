# 🤖 AI Voice Receptionist & Appointment Setter

An AI-powered appointment management workflow built with **n8n, Vapi, Google Calendar, and Airtable**.

## ⚙️ Key Functions

- **Check Availability:** Checks Google Calendar and suggests alternative time slots.
- **Book Appointments:** Creates calendar events, generates Google Meet links, and saves booking records.
- **Reschedule Appointments:** Updates existing appointments in Google Calendar and Airtable.
- **Cancel Appointments:** Processes cancellations and updates appointment records.
- **Manage Records:** Tracks customer information, appointment details, and booking statuses.

## 🛠️ Technologies Used

- **n8n** — Workflow automation
- **Vapi** — AI voice receptionist
- **Google Calendar** — Appointment scheduling
- **Google Meet** — Meeting links
- **Airtable** — Appointment database
- **JavaScript** — Data processing and timezone conversion
- **Webhooks** — Communication between Vapi and n8n

## 🔁 How It Works

Customer Call → Vapi → n8n Webhook → Appointment Processing → Google Calendar & Airtable → Customer Response
